# Pocket Arena Expanded

This is the initial skeleton for Pocket Arena Expanded. It contains a modular structure and starter code for the game: core loop, player, enemies, audio, UI and styles. Build and run instructions are below.

Run locally:
1. Clone the repo: git clone https://github.com/soul-byte-web/pocket-arena-expanded.git
2. Open index.html in a browser (or run a local static server such as: npx http-server or python -m http.server)

This initial commit sets up the project and the home screen. Subsequent branches will add full gameplay, audio, sprites, shop, and equipment systems.
